15. Acceptance Criteria
The project shall be considered complete only when:
•	Fully responsive across mobile, tablet, and desktop devices.
•	Cross-browser compatible (Chrome, Edge, Firefox & Safari).
•	All enquiry and booking forms work without errors.
•	Admin CRUD operations function correctly.
•	Blog management is fully operational.
•	Leads are stored accurately in the database.
•	Lead status management and filtering work correctly.
•	Google Maps Location Picker functions correctly.
•	Google Analytics & Search Console integration is ready.
•	Both websites are deployed independently with separate codebases, databases, admin panels, blogs, leads, and SEO settings.
•	No critical Google PageSpeed or Core Web Vitals issues.
•	Source code and documentation are delivered.
•	Production deployment is completed and verified.

18. Warranty & Support
The developer shall provide six (6) months of post-deployment technical support from the date of project handover.
Support Includes
•	Website crash recovery
•	Website downtime troubleshooting
•	Critical bug fixes
•	Form submission issues
•	Database-related issues
•	Hosting configuration assistance
•	SSL configuration issues
•	Website restoration from available backups
•	Minor browser compatibility fixes
•	Performance issues caused by the delivered code
•	Technical deployment assistance
Exclusions
The following are not included unless agreed separately:
•	New features or modules
•	UI/UX redesign
•	Major content additions
•	Third-party API changes
•	Hosting provider outages
•	Domain or DNS issues caused by registrar changes
•	Issues caused by third-party modifications after delivery
•	SEO ranking guarantees
